# AI সেলস ইনবক্স — ক্রোম এক্সটেনশন

> **এটা কী করে (সহজ ভাষায়):** Facebook/Messenger/Business Suite-এ চ্যাট
> করার সময় পাশে একটা ছোট প্যানেল দেখায় — দ্রুত উত্তর কপি করা যায়,
> প্রোডাক্টের দাম খোঁজা যায়, আর কোন চ্যাটে AI উত্তর দিচ্ছে সেটা দেখা যায়।
> **এটা নিজে মেসেজ পাঠায় না** — লেখা কপি করে আপনিই চ্যাটে বসিয়ে
> পাঠাবেন। পাসওয়ার্ড এক্সটেনশনে রাখা হয় না।

## ১. লোড করা (unpacked — ২ মিনিট)

1. Chrome খুলে ঠিকানা বারে লিখুন: `chrome://extensions`
2. ওপরে ডানদিকে **Developer mode** চালু করুন।
3. **Load unpacked** চাপুন।
4. এই ফোল্ডারটি বেছে নিন: `workspace/ai-sales-inbox/chrome-extension`
5. টুলবারে এক্সটেনশনের আইকন (🛍️) দেখা যাবে — সেটা পিন করে রাখুন।

আপডেট করতে: `chrome://extensions`-এ এক্সটেনশনের **Update**/রিফ্রেশ চাপুন,
বা ফোল্ডারটি আবার Load unpacked করুন।

## ২. সেটিংস (প্রথমবার)

1. এক্সটেনশনের আইকনে ক্লিক করুন (popup খুলবে)।
2. **API ঠিকানা:** নিজের কম্পিউটারে চালালে `http://localhost:4000`-ই
   থাকবে। সার্ভার অন্য কোথাও হলে সেটার ঠিকানা বসান।
3. **লগইন টোকেন:** ড্যাশবোর্ডে লগইন করুন → `F12` চাপুন →
   **Application** → **Local Storage** → `token`-এর মান কপি করে এখানে
   বসান। টোকেন শুধু আপনার ব্রাউজারে থাকে (`chrome.storage.local`) —
   কোথাও পাঠানো হয় না, আর popup-এ দেখানোও হয় না।
4. **ড্যাশবোর্ড ঠিকানা:** নিজের কম্পিউটারে `http://localhost:3000`।
5. **সংরক্ষণ করুন** চাপুন।

> টোকেন ছাড়া দ্রুত উত্তর (কপি) কাজ করবে, কিন্তু প্রোডাক্ট খোঁজা আর
> চ্যাটের তালিকা কাজ করবে না — সেগুলোর জন্য টোকেন লাগবে।

## ৩. যা যা করতে পারবেন

| জায়গা | কী করা যায় |
|---|---|
| **Popup** (আইকনে ক্লিক) | প্রোডাক্ট নাম দিয়ে খোঁজা → দাম+স্টকসহ উত্তর তৈরি → কপি; দ্রুত উত্তর বেছে কপি; খোলা চ্যাটের তালিকা — কোনটায় AI উত্তর দিচ্ছে, কোনটায় মানুষ নিয়েছে; "আমি নিচ্ছি" / "AI-কে ফেরত দিন" বোতাম। |
| **Facebook/Messenger পেজ** | নিচে ডানদিকে ছোট প্যানেল — দ্রুত উত্তর কপি করা যায়, ড্যাশবোর্ডের লিংক থাকে। |

## ৪. যা যা করে না

- নিজে থেকে চ্যাটে মেসেজ **পাঠায় না** — সব লেখা আপনিই দেখে পাঠাবেন।
- আপনার চ্যাটের লেখা **পড়ে না** — content script শুধু প্যানেল বসায়।
- পাসওয়ার্ড রাখে না; টোকেন শুধু আপনার ব্রাউজারের লোকাল স্টোরেজে থাকে।
- দাম/স্টক কখনো নিজে থেকে বানায় না — সব API/ডেটাবেজ থেকে আসে।

## ৫. ফাইলগুলো

- `manifest.json` — Manifest v3, শুধু `storage` পারমিশন + API-র সাথে
  কথা বলার অনুমতি (`http://localhost:4000/*` আর `https://*/*` — নিজের
  API সার্ভার অন্য ডোমেইনে হলে `host_permissions` সরু করে সেটা বসান)।
- `popup.html` / `popup.css` / `popup.js` — popup (প্রোডাক্ট খোঁজা,
  দ্রুত উত্তর, চ্যাটের তালিকা, AI/মানুষ বদলানো)।
- `content.js` / `content.css` — Facebook/Messenger/Business Suite
  পাতায় ছোট সহায়ক প্যানেল।
- `icons/icon16.png`, `icon48.png`, `icon128.png` — আইকন (PIL দিয়ে
  বানানো সাধারণ সবুজ "AI" আইকন; চাইলে বদলে নিন)।
- `README.md` — এই ফাইল।

## ৬. সমস্যা হলে

- **প্রোডাক্ট খুঁজে পাচ্ছে না:** API চালু আছে কি না দেখুন
  (`http://localhost:4000/api/health`) আর টোকেন ঠিক আছে কি না দেখুন।
- **প্যানেল দেখা যাচ্ছে না:** পাতাটি রিফ্রেশ করুন; শুধু
  `facebook.com`, `messenger.com`, `business.facebook.com`-এই প্যানেল
  আসে।
- **"401 / টোকেন" এরর:** ড্যাশবোর্ড থেকে আবার লগইন করে নতুন টোকেন
  বসান (টোকেন মেয়াদ শেষ হলে এমন হয়)।
